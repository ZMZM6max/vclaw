# VClaw Telegram 验收清单

## 前置条件

1. 运行 `python scripts/preflight_check.py` 全部通过
2. Docker Desktop 已启动
3. `.env` 中 `TELEGRAM_BOT_TOKEN` 和 `OPENAI_API_KEY` 已配置

## 启动 Bot

```bash
python telegram_bot.py
```

终端应显示初始化完成，Bot 开始监听消息。
