# 架构设计文档

本目录包含 VClaw 项目的高层架构设计文档。

## 文件说明

| 文件 | 说明 |
|------|------|
| `sdd.md` | 软件设计文档 (Software Design Document) - 完整的架构设计、接口规范、数据流图 |
| `Architecture_Overview.xml` | 架构总览 XML 规范 - 六层结构、耦合矩阵、数据流图的可视化定义 |

## 阅读建议

1. **快速了解**：先阅读 `sdd.md` 的"架构总览"章节
2. **深入理解**：结合 `Architecture_Overview.xml` 查看详细规范
3. **实施参考**：查看 docs/specs/ 目录下的各层详细 XML 规范
