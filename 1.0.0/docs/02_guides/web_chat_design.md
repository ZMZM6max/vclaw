# VClaw Web 聊天界面设计方案

## 概述

通过 Web 界面与 VClaw 进行实时聊天，支持流式响应（打字机效果）。

## 技术栈

| 组件 | 技术 | 说明 |
|------|------|------|
| 后端 | FastAPI + WebSocket | 实时双向通信 |
| 前端 | HTML + JavaScript | 轻量级，无需构建 |
| UI 框架 | Tailwind CSS (CDN) | 现代化样式 |
| 实时通信 | WebSocket | 低延迟，支持流式 |

## 实现步骤

### 1. 创建 L1 Web 接入层

文件: `src/l1_web_interface.py`

- 接收 WebSocket 消息
- 转换为 StandardEvent
- 发送到 L2
- 流式返回响应

### 2. 创建 FastAPI 应用

文件: `src/web_server.py`

- 挂载静态文件（HTML/CSS/JS）
- WebSocket 路由
- CORS 配置

### 3. 创建前端界面

文件: `src/web/static/index.html`

- 现代化聊天 UI
- WebSocket 客户端
- 流式消息显示
- Markdown 渲染

### 4. 启动脚本

文件: `start_web.py`

- 一键启动 Web 服务
