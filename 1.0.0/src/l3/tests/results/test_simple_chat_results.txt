def bubble_sort(arr):
    n = len(arr)
    for i in range(n - 1):
        for j in range(n - 1 - i):
            if arr[j] > arr[j + 1]:
                # 交换位置
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr

# 示例

## TC-L3-001: 中文简单对话
**时间**: 2026-04-13 16:30:27
**输入**: "你好，怎么做西红柿炒鸡蛋"

**LLM 返回**:
当然可以！西红柿炒鸡蛋是一道很家常、好做又下饭的菜。

## 食材
- 西红柿 2个
- 鸡蛋 3个
- 葱花 少许
- 盐 适量
- 白糖 少许（可选）
- 食用油 适量

## 做法
1. **处理食材**
   - 西红柿洗净切块。
   - 鸡蛋打入碗中，加入少许盐，搅散。
   - 葱切成葱花。

2. **炒鸡蛋**
   - 锅里放油，油热后倒入鸡蛋液。
   - 等蛋液稍微凝固后，用锅铲快速翻炒成块。
   - 鸡蛋炒熟后先盛出来。

3. **炒西红柿**
   - 锅里再放一点油，放入西红柿翻炒。
   - 炒到西红柿出汁、变软。
   - 如果喜欢汤汁多一点，可以加一点点水。

4. **调味**
   - 加少许盐。
   - 如果西红柿比较酸，可以加一点点白糖提味。

5. **合炒**
   - 把炒好的鸡蛋倒回锅里，和西红柿一起翻炒均匀。
   - 撒上葱花，炒匀后即可出锅。

## 小技巧
- 鸡蛋先炒再盛出，口感会更嫩。
- 西红柿先炒出汁，味道更浓。
- 喜欢滑嫩口感的话，鸡蛋里可以加一小勺清水。
- 喜欢浓郁一点的，可以多炒一会儿让汤汁更厚。

如果你愿意，我还可以给你一个**“家常版更好吃的详细步骤”**，或者教你做**“番茄炒蛋盖饭”**。
