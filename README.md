# vclaw · 类 OpenClaw 智能体（Agent Harness）

基于 ReAct 范式实现的智能体运行时框架（Agent Harness）：将 LLM 置于「任务循环 + 工具系统 + 会话记忆」构成的执行框架中，支撑多工具协作完成复杂任务链。

## 核心能力

- **任务循环（ReAct）**：推理 → 选择工具 → 传参执行 → 结果回填上下文 → 继续推理，迭代直至任务完成
- **工具系统**：工具注册、选择与参数传递校验，执行结果回填上下文供模型继续推理，支持多工具接力
- **会话记忆**：历史会话与任务关键信息的保存、读取与再加载，支撑连续对话与信息复用
- **质量保障**：「AI 办公助手」端到端测试用例集 + 集成测试设计，覆盖多工具任务链路（推理规划、工具选择、参数构造、结果回填）
